# Privacy Policy / 隐私政策

**Last Updated / 最近更新**: October 2026

## English

Smart Scheduler ("the Application") is an ultra-lightweight Windows CPU topology affinity and dynamic priority management utility. We value your privacy and are committed to complete transparency.

### 1. Zero Telemetry & No Data Collection
Smart Scheduler does **not** collect, record, track, store, or transmit any personally identifiable information (PII), system telemetry, crash logs, or analytics.

### 2. Completely Offline (Zero Network Activity)
The Application operates 100% locally on your personal computer. It does not open any network sockets, initiate outbound web connections, or contact any remote servers or cloud services.

### 3. Local Data Storage & Clean Uninstallation
All user configuration rules (CPU affinity preferences, process exemptions, priority settings) are saved solely on your local device in the standard Windows isolated application storage container (`%LOCALAPPDATA%\Packages\<PackageFamilyName>\LocalState\config.toml`).

When the Application is uninstalled via Windows Settings or the Microsoft Store, Windows automatically and completely removes this directory, leaving zero residual files or registry keys on your system.

## 简体中文

Smart Scheduler（“本应用”）是一款超轻量级 Windows CPU 拓扑亲和性与动态优先级调度工具。我们重视您的隐私，并承诺保持完全公开透明。

### 1. 零遥测与零数据收集
Smart Scheduler **不会**收集、记录、追踪、存储或传输任何个人身份信息（PII）、系统遥测数据、崩溃日志或使用情况统计。

### 2. 纯本地运行（无任何网络活动）
本应用 100% 在您的本地计算机上独立运行。应用不会创建任何网络连接套接字，不会发起任何网络通信，也不会访问任何远程服务器或云端服务。

### 3. 本地配置存储与无残留卸载
您的所有个性化调度规则（CPU 亲和性掩码、进程排除名单、优先级设置等）仅保存在本地 Windows 隔离应用存储目录中（`%LOCALAPPDATA%\Packages\<PackageFamilyName>\LocalState\config.toml`）。

当您通过 Windows“设置”或 Microsoft Store 卸载本应用时，Windows 系统将自动清理并删除该应用数据目录，不残留任何临时文件或垃圾注册表项。
